Recuit simulé en Python
Contexte
Projet réalisé dans le cadre du module CSC217 - IA et Calcul Scientifique au CNAM.
L'objectif était d'implémenter l'algorithme du recuit simulé (Simulated Annealing) en Python à partir d'un pseudo-code fourni, puis de l'appliquer à une fonction de Rastrigin en deux dimensions dont le minimum global est atteint en (0,0).
Ce que contient le projet
    • Implémentation du recuit simulé en Python
    • Génération de solutions voisines
    • Visualisation de la convergence
    • Comparaison de plusieurs stratégies de refroidissement
Fonctions de refroidissement étudiées
    • Fast
    • Exponentielle
    • Boltzmann
    • Cauchy
Résultats
Les essais réalisés montrent l'influence de la température initiale et de la fonction de refroidissement sur la convergence de l'algorithme.
Technologies utilisées
    • Python
    • NumPy
    • Matplotlib
    • Jupyter Notebook
